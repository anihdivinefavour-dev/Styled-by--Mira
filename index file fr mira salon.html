Admin System Setup

This is a setup guide, not a live admin login. The Supabase backend has not been connected yet.

01

Secure sign-in

Supabase Auth will authenticate the owner and approved staff accounts. Public sign-up should be disabled.

02

Service manager

After connection, authorised staff can create, edit, archive or delete services, set prices, and upload photos.

03

Bookings & orders

The dashboard will list customer bookings, orders, and payment states from the shared database.

04

Staff permissions

Owner role manages staff access. Staff permissions will be enforced by database policies, not just hidden buttons.

Connection status

Not connected. No Supabase project URL, public anon key, database tables, storage bucket, or authentication policies have been configured in this preview.

Production setup checklist

  1. Create a Supabase project and save its project URL and publishable/anon key.
  2. Run the database schema and row-level security policies for profiles, services, bookings, orders and order items.
  3. Create a private staff allowlist and assign the owner role securely; invite staff through Supabase Auth.
  4. Create a service-images Storage bucket with upload rules restricted to authenticated authorised staff.
  5. Connect the website to Supabase using its client SDK and environment variables. Never place a service-role key in browser code.
  6. Deploy the website on a host with environment-variable support, then test staff access, uploads, bookings and payment webhooks.

Important: The current customer cart and payment action remain demo-only. Do not accept real customer payments until a payment provider and server-verified webhook flow are configured.
